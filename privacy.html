Privacy Policy

Ranking Shorts · Last updated 26 October 2026

Ranking Shorts is a private tool used by one person, the owner of the YouTube channel PYRO (@pyro9039), to publish videos to that channel. It runs on the owner's own computer. It has no other users, no website accounts and no server that collects data.

YouTube API Services

Ranking Shorts uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

What Google user data is accessed

When the owner signs in with Google, the tool requests two permissions:

  • youtube.upload: to upload the videos the tool creates, with their title, description, tags and scheduled publish time.
  • youtube.readonly: to read the channel's basic details and the view counts of videos the tool uploaded.

It does not access email, contacts, comments, subscribers, viewing history, payment information or any other channel or account.

How the data is used

  • Upload permission is used only to publish videos the owner's tool has made.
  • View counts are used only to decide which video topics to make more of.

Google user data is not used for advertising, is not sold, and is not used to train AI models. The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Where the data is stored

  • The Google sign-in token is stored in a file on the owner's own computer and is never uploaded anywhere.
  • Uploaded video IDs and their view counts are stored in a local file on the same computer.
  • No Google user data is stored on any server operated by this tool.

Sharing

Google user data is not shared with, transferred to or disclosed to anyone. To choose clips and write on-screen labels, the tool sends still frames from public source clips, with their public titles, to Anthropic's Claude API. These requests contain no Google account data.

Retention and deletion

  • Access can be revoked at any time at myaccount.google.com/permissions, which makes the stored token stop working immediately.
  • Deleting the tool's folder removes the token and all locally stored data.
  • Locally stored view counts are kept only as long as the tool is in use.

Creators

Videos credit the creators of the original clips in their descriptions. A creator who wants a clip removed or credited differently can use the contact below, and it will be handled promptly.

Changes and contact
